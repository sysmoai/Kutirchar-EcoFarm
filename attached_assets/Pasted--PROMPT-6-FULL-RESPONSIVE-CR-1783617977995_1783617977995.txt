3) FIX RULES
────────────────────────────────────
- mobile-first লেখো: base = mobile, তারপর sm/md/lg/xl progressively enhance।
- Tailwind responsive utility + brand token ব্যবহার; magic number নয়।
- fluid spacing/size: clamp() ও container query যেখানে উপযুক্ত।
- overflow ঠিক করতে min-w-0, flex-wrap, truncate/line-clamp, overflow-x-auto সঠিকভাবে।
- viewport height: 100dvh/100svh ব্যবহার (mobile browser bar issue এড়াতে)।
- image: srcset + sizes + width/height + object-fit; ভারী animation/3D scene ছোট/low-power device-এ lazy বা simplified।
- reduced-motion + কম-শক্তির ডিভাইসে animation degrade।
- কোনো কন্টেন্ট বা ভাষা হারাবে না; শুধু layout/responsive ঠিক করবে।
