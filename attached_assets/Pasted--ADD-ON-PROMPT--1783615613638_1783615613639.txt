3) GENERATION — সেরা মডেল, স্মার্ট ব্যবহার
──────────────────────────────────────────────
- Raster/photoreal: সর্বোচ্চ মানের available image-generation model ব্যবহার করবে; high-res, seed/style lock করে সব asset-এ art-direction consistency রাখবে।
- Diagram/icon: vector-first (SVG) — infinitely scalable, ছোট file, brand color token inline।
- Motion: Lottie JSON (lottie-react); জটিল হলে GSAP/SVG line-draw; 3D শুধু r3f + drei (lazy, poster fallback)।
- প্রতিটি generation-এ প্রম্পটে থাকবে: brand palette, দেশীয় চরাঞ্চল প্রেক্ষাপট, auditor-tone, "illustrative", কোনো text/watermark নয়, কোনো বাস্তব ব্যক্তির মুখ নয়।
- Fallback: কোনো asset মানসম্পন্নভাবে না হলে vector/SVG version দিয়ে replace করবে — কখনো নিম্নমানের/artifact-যুক্ত ছবি রাখবে না।

──────────────────────────────────────────────
4) TECHNICAL DELIVERY
──────────────────────────────────────────────
- Format: photoreal → WebP/AVIF (fallback PNG); diagram/icon → SVG; motion → Lottie JSON/optimized।
- Responsive srcset + width/height সেট (CLS<0.1); lazy-load (hero eager/preload)।
- প্রতিটি image-এ দ্বিভাষিক descriptive alt + "Illustrative" indicator।
- সব asset src/assets/ (images/, icons/, lottie/, og/)-এ organized; নাম kebab-case।
- License: শুধু self-generated বা licensed asset; কোনো copyrighted/watermarked stock নয়। কিছুই sensitive/private নয়।

──────────────────────────────────────────────
5) QUALITY VERIFICATION LOOP (নিজে যাচাই — pass না হলে regenerate)
──────────────────────────────────────────────
প্রতিটি asset-এর জন্য চেক:
☐ Art direction consistent (palette, আলো, style, subject দেশীয় ও বাস্তবসম্মত)।
☐ Brand token color মিলছে; brand name/logo বিকৃত নয়।
☐ কোনো generation artifact নেই (বিকৃত হাত/পা/মুখ, garbled text, অসংগতি)।
☐ কোনো আসল ব্যক্তির মুখ, NID, বা misleading "proof" নেই; "Illustrative" লেবেল আছে।
☐ Resolution/sharpness যথেষ্ট (hero ≥2× retina); file size performance budget-এ।
☐ alt/aria দ্বিভাষিক; reduced-motion respect (animation)।
☐ পেজে বসানোর পর layout/CLS ঠিক; visually cohesive।
কোনো item fail → asset regenerate/replace, তারপর আবার চেক। সব pass না হওয়া পর্যন্ত continue।

──────────────────────────────────────────────
6) EXECUTION (continuous)
──────────────────────────────────────────────
STEP A: art-direction spec + seed/style lock তৈরি করো।
STEP B: SECTION 2-এর ক্রমে asset generate করো (hero → ecosystem → science → roadmap → map → products/digital → people → og → lottie/3D)।
STEP C: optimize + সঠিক পেজ/section-এ integrate (v5 storyboard অনুযায়ী animation সহ)।
STEP D: SECTION 5 QA loop প্রতিটি asset-এ চালাও; fail হলে regenerate।
STEP E: full-site visual pass — cohesion, performance (Lighthouse ≥95 বজায়), a11y; তারপর রিপোর্ট: asset তালিকা + কোনটা photoreal vs vector + QA status + assumptions।
থামবে না যতক্ষণ সব asset মানসম্পন্ন, integrated ও QA-passed না হয়।
